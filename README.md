# Alexsvianzon Tap

## How do I install these formulae?

`brew install alexsvianzon/tap/<formula>`

Or `brew tap alexsvianzon/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "alexsvianzon/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
